Automated Bacterial Colony Counter
Embedded imaging instrument on a Raspberry Pi 5, built for the Ryberg Lab at UConn, that backlights agar plates and quantifies bacterial colonies. Run blind against 250 held-out synthetic plates it had never seen, the Python/OpenCV pipeline (illumination correction, watershed segmentation, morphometrics) reached a pooled F1 of 0.869 with precision 1.000 on every plate: zero false colonies, and a 15.75% mean count error (5.31% on the passing sets), benchmarked against peer-reviewed results for OpenCFU and ColonyDoc-It. Two-layer anomaly detection and organism-aware profiles run on a custom KiCad power PCB (designed and ordered). Biological validation on real agar is next.
Python OpenCV Raspberry Pi 5 Flask scikit-learn KiCad Linux

STM32 Bare-Metal GPIO Driver
A register-level GPIO driver for the STM32F411RE Nucleo, written from scratch in C with no HAL, configuring 9 MMIO registers across three peripherals (RCC, GPIOA, USART2) directly via memory-mapped I/O. The flash image is 752 bytes and the output signal timing is verified on a logic analyzer rather than assumed. Roadmap in the repo: UART, I2C, SPI, ADC with DMA, and FreeRTOS.

Two-Compartment Pharmacokinetic Simulator
Python two-compartment pharmacokinetic model that integrates the ODE system with an adaptive RK45 solver. Supports IV bolus, IV infusion, and oral dosing, and derives AUC, Cmax, Tmax, and half-life. Validated against the closed-form analytic solution to under 0.001% error on AUC and half-life, with a 3.03 ms single-dose runtime.

FocusGuard: Fatigue & Stress Monitor
Lightweight macOS menu bar app that fuses two real-time signal streams, camera (blink rate and eye openness via MediaPipe face mesh) and keyboard behaviour, into live Fatigue and Stress scores. Built as a multi-threaded producer-consumer system with thread-safe lock-guarded shared state, it runs at 26 ms median sensor-to-score latency and 30 fps, holding 116 MB steady-state RSS with zero crashes over a 6-minute soak (10/10 unit tests). A live Flask dashboard charts current and historical scores. Fully local: no cloud, no accounts.
Python MediaPipe OpenCV PyObjC Flask pynput threading

HuskyBook: Peer-to-Peer Campus Directory
Full-stack web app connecting UConn students who offer personal-care services with students looking to book them. A Node and Express REST API (16 endpoints over a 5-table SQLite schema) and a Vite front end are wired together as npm workspaces, with magic-link auth and privacy-by-design access control: sensitive fields such as exact location and contact stay out of the public browse endpoint and release only after a provider accepts a request, with ownership enforced at the data layer. Read endpoints answer in 0.07 to 0.16 ms and sustain 10,600 requests per second, with 32/32 tests passing across 1,724 SLOC. Now archived: a working product that, on reflection, solved a problem neither side had, so I stopped rather than build features nobody needed.
JavaScript Node.js Express Vite SQLite REST API
